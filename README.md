# Online Quiz Platform

## Project Description
This is a simple Online Quiz Platform developed using Python. It allows users to answer multiple-choice questions and displays their final score, percentage, and grade.

## Features
- User name input
- Multiple-choice questions
- Correct and wrong answer checking
- Invalid input handling
- Retry option for wrong answers
- Final score calculation
- Percentage calculation
- Grade system

## Technologies Used
- Python

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python quiz.py
```
